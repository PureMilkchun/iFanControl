# iFanControl 3.0 · 简洁、优雅、高效

这次，我们重新梳理了从启动、查看状态、调整设置，到更新和反馈的整个使用流程。让界面更简洁，操作更直接，让等待有提示，让完成有回应。

1. **启动过程看得见**
   新增轻量启动界面，显示设备识别、恢复设置和准备控制等实际阶段。初始化完成后自动收起，减少等待时“软件是不是卡住了”的疑惑。

2. **更简洁的菜单，更清楚的状态**
   重新整理菜单栏主菜单，常用控制操作直接可达，偏好设置集中收纳。明确显示当前控制模式，优化状态与时间的表述，让信息更容易理解。

3. **信息栏设置更直观**
   优化完整、简洁、迷你三种展示模式的设置布局。迷你模式支持组合预览、分别设置上下两行及快速交换，调整时就能看到最终样式。

4. **曲线编辑更精准、更顺手**
   新增控制点温度与转速的数值编辑，面板按需展开；拖动与数值输入同步。增加明确的预设重命名入口，优化曲线、控制点和坐标的呈现，并补充输入校验、编辑状态及保存失败提示。

5. **设置完成，反馈更明确**
   优化手动转速与安全兜底转速窗口，突出目标数值和应用操作。保存成功后给出明确反馈，失败时保留编辑内容；曲线保存等完成提示采用轻量打勾动画，并适配系统“减少动态效果”设置。

6. **更新流程更完整**
   检查更新、下载安装包、校验文件和打开安装器都有清楚的状态提示。下载显示实际进度，支持取消，失败后可重试。继续使用 macOS 原生 PKG 安装，保留系统安装完成页；后续通过新版更新器完成升级并重新打开应用时，会显示简短的版本更新确认。

7. **帮助与功耗信息更易读**
   调整“关于／帮助”的侧栏字号、选中区域与内容布局，新增“访问官网”按钮。梳理快速自检、诊断导出、联系支持和卸载入口；优化功耗页的读数层级、首个样本等待及暂不支持状态说明。

8. **反馈更方便，也更清楚**
   保留主菜单里邀请你反馈的文本框，点击即可进入独立反馈窗口。支持 ⌘↩ 发送；发送失败保留已输入内容，便于重试；发送状态、成功反馈和频率限制说明更加明确。

9. **新增独立 Beta 更新通道**
   加入默认隐藏的开发者模式与独立 Beta 更新线路，供开发迭代使用。普通用户默认继续接收正式版；开发者可在解锁后单独选择 Beta，通过相同的在线更新流程验证新版本。

同时，改善中英文文案、深浅色显示、键盘操作和辅助功能标签等细节。

本次沿用现有风扇控制策略，保留原有曲线、预设和使用偏好。

**旧版升级说明：**2.9.8 等仍使用旧更新器的版本，会先收到 2.9.9/build52 过渡版本；完成安装并重新打开后，再通过 PKG 升级至 3.0。已经使用 2.9.9/build52 的用户可直接在线升级。
