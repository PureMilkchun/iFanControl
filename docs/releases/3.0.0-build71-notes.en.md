## iFanControl 3.0 · Simple, elegant, efficient

We have refined the journey from launch and everyday settings to updates and feedback, with a clearer interface, more direct controls, and useful feedback while you wait and when an action finishes.

1. **Visible startup progress.** A lightweight panel shows device detection, settings restoration and control preparation, then closes when initialization is ready.
2. **A cleaner menu and clearer status.** Frequently used controls remain directly accessible, preferences are grouped together, and control mode and recorded-time wording are easier to understand.
3. **More intuitive menu bar display settings.** Refined layouts for full, compact and mini modes, including a combined preview and quick swapping of the mini display's two lines.
4. **More precise curve editing.** Enter control point temperatures and RPM values in an optional numeric panel, synchronized with dragging. A dedicated preset rename action, clearer graph presentation, input validation, edit status and save-error feedback make editing easier.
5. **Clearer settings feedback.** Manual and safety RPM windows emphasize the target and Apply action. Failed saves retain your edits. Lightweight checkmark confirmations for actions such as saving a curve respect Reduce Motion.
6. **A more complete update experience.** Clear checking, downloading, verification and installer handoff states, real download progress, cancellation and retry. Installation continues through the native macOS PKG installer and its completion page. Subsequent updates performed by the new updater can show a brief version confirmation after relaunch.
7. **More readable help and power information.** Improved About / Help navigation, a Visit Website button, clearer diagnostic and support actions, and more useful power-reading, first-sample and unsupported-device states.
8. **Easier feedback.** The menu's feedback invitation remains available. Press Command-Return to send, retain entered text after a failed attempt, and see clearer sending, delivery and rate-limit messages.
9. **A separate Beta update channel.** An initially hidden developer mode provides an optional Beta channel through the same online update workflow. Regular users continue to receive stable releases by default.

Also refined Chinese and English text, light and dark appearances, keyboard interactions and accessibility labels.

The existing fan control strategy, curves, presets and preferences are preserved.

**Upgrading older versions:** Clients still using the ZIP updater, including 2.9.8, first receive the 2.9.9/build52 bridge. After installation and relaunch, they can upgrade to 3.0 through PKG. Users already on 2.9.9/build52 can update directly.
