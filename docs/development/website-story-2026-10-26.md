## 内容与画面

菜单里的「告诉开发者」邀请框保持醒目，说明点击后进入独立窗口。原反馈案例轮播移到这个场景；曲线段另配有日期依据的 Y 轴建议。删除写死的平均响应/上线速度，以及将 build 当成构建迭代次数的指标。月活放在日常常驻语境中，明确近30天及机型实测边界，不作为全机型稳定性承诺。

十张中英文 WebP 来自现有原生生产 UI 控制器的隔离验收截图，原始路径、裁切和哈希见 JSON。当前3.0沿用这些界面；数字是演示数据，不宣称是这次从真实硬件运行中拍摄。菜单只裁掉验收宿主标题及空白桌面，没有绘制或改写界面文字。曲线/设置图片提供原尺寸链接。图像共约248KB，没有重编译或启动原生 App。

## 特色动画

扇叶、滚动提示及整份原 CSS 保留；原动画模块也保留。新的版本化 Calligraph 适配只处理文字分组及减少动态效果的静态分支：沿用原库版本、逐字变化、漂移和900ms/180ms揭示节奏。中文按分句、英文按单词换行，并允许文字放大时进一步换行，避免句号孤行与英文断词。

已实际观察扇叶 transform 连续变化，离开首屏后暂停；标题从引导短句变成目标标题；月活从00变成接口值197。原案例滑动继续工作，增加有名称的切换按钮和暂停/继续；键盘焦点可见，当前案例具备可访问状态，悬停或聚焦时暂停。
