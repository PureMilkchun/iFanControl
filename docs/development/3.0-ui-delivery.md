## 文件整理建议

先明确发布入口与验证入口，再拆文件，避免本次UI验收和目录迁移相互干扰。第一步可将当前四个小型UI辅助类归入 `Sources/MacFanControl/UI/`，将原生控制器从大型main.swift按Updater、菜单、设置、帮助支持逐块提取；保持同一target和访问边界，每次提取独立构建/验收。硬件、控温、IOReport适配应保持独立，不以UI抽取改变调用线程或计时器。

测试夹具后续集中到 `Tests/`（更新协议、原生控制器与视觉驱动分开），`packaging/pkg/` 保留构建/通道保护/发布检查入口。生成的包、线上快照和视觉证据统一留在已忽略的output目录，文档引用最终版本。历史包与实验页面先列清单再归档，不按名字直接删除。详细原始整理理由见 `3.0-preparation.md`；本次没有顺带移动历史文件或改官网工程。
