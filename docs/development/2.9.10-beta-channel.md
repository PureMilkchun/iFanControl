## 发布契约

| 项目 | 正式 | Beta |
| --- | --- | --- |
| feed | update-manifest-pkg.json | update-manifest-beta.json |
| App 身份 | 原 bundle id 与安装目录 | 同一 App，配置保持兼容 |
| 包路径 | iFanControl-macOS.pkg?build=N | 独立带版本/build 文件名 |
| manifest 元数据 | release_channel: stable（兼容省略） | release_channel: beta；可指向 promoted stable |
| 当前版本身份 | 原数字版本/build | 数字版本/build 加 Info.plist IFanControlReleaseChannel: beta |
| 失败 Release 链接 | 保留原 v{version} 拼接 | manifest 可选 release_url，缺失时使用 Releases 首页 |

Beta 包不能覆盖官网正式包。正式通道拒绝声明为 Beta 的元数据。发布更高 build 的正式版时，Beta feed 同步该正式版的独立副本，保证开发者也能走同一路线进入正式版。两份 native feed 都设置 no-store。

legacy `update-manifest.json` 与两份 ZIP 永久固定 2.9.9/build52。Beta 独立测试期间，正式 manifest、正式 PKG、`/download`、官网页面/时间线以及正式 GitHub Release 都保持原版本。
